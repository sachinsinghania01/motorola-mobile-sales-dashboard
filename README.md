# motorola-mobile-sales-dashboard
Motorola Mobile Sales Dashboard
Project Overview

Designed an interactive Power BI dashboard to analyze Motorola mobile sales performance from 2021 to 2024.

Objectives :-
Track revenue,
Analyze monthly sales,
Compare cities,
Monitor quantity sold,
Identify top performing models,
Study customer ratings,
Payment method analysis,

Dashboard Features :-
KPI Cards,
Time Intelligence,
Drill-through,
Interactive Filters,
Map Visualization,
Dynamic Charts,

Tools Used:-
Power BI,
Power Query,
DAX,
Data Modeling,
Excel,
KPIs,
Total Sales,
Total Quantity,
Average Rating
Average Price
Transactions
